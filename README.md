# End-to-End Data Analytics Project

## Objective
To perform exploratory data analysis and build an interactive Power BI dashboard
for actionable business insights.

## Project Structure
- data/: Raw dataset used for analysis
- notebooks/: Jupyter notebook for EDA
- dashboard/: Power BI dashboard file
- 
## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI
- 
## Workflow
1. Data understanding and cleaning
2. Exploratory Data Analysis (EDA)
3. Insight generation
4. Dashboard creation in Power BI

## Dataset
The dataset used in this project is publicly available and used for educational purposes only.
